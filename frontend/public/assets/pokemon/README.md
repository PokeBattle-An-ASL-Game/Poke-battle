# Opponent illustration placeholders

This public-repository overlay intentionally excludes the four separately supplied PNGs because public distribution/demo rights have not been established. Catalog expects `bulbasaur.png`, `squirtle.png`, `onix.png`, and `goldeen.png` here. Obtain approval or replace with original, rights-cleared art before enabling the corresponding levels. The `.gitignore` excludes PNGs until the team explicitly changes its rights policy. Do not treat missing files as a built UI or a licensed asset.
